# 🍽️ Zomato Business Performance Dashboard

## 📌 Project Overview

This project presents an interactive Power BI dashboard developed to analyze Zomato business performance using order, customer, restaurant, and delivery data. The dashboard enables stakeholders to monitor key performance indicators, identify trends, and make data-driven business decisions.

---

## 📊 Dashboard Features

- Total Revenue
- Total Orders
- Average Order Value
- Average Delivery Time
- Average Customer Rating
- Revenue by City
- Revenue by Cuisine
- Top 10 Restaurants by Revenue
- Orders by City
- Orders by Payment Mode
- Order Status Analysis
- Interactive Slicers (City, Restaurant, Date, Payment Mode, Order Status)

---

## 🛠️ Tools & Technologies

- Power BI
- DAX
- Power Query
- SQL Server
- Microsoft Excel

---

## 📈 Key Business Insights

- Generated approximately **₹8.2 Million** in revenue from **10,000 orders**.
- Average Order Value: **₹821.71**
- Average Delivery Time: **37.58 minutes**
- Average Customer Rating: **3.0/5**
- More than **90% of orders were successfully delivered**.
- Identified the **Top 10 Restaurants by Revenue**.
- Compared revenue and order performance across cities and cuisine categories.
